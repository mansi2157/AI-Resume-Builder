## About

AI-Powered Resume Builder is an intelligent application that helps you create professional, ATS-optimized resumes with the power of artificial intelligence. Built with modern web technologies and integrated with Gemini AI for smart content suggestions.

## ✨ Features

### 🤖 AI-Powered Content Generation

- **Smart Content Suggestions**: AI-powered paragraph writing with ATS-friendly keywords
- **Real-time Optimization**: Get suggestions on where to improve keyword usage
- **Gemini AI Integration**: Configurable API integration for intelligent content assistance

### 🎨 Modern Design & Templates

- **Professional Templates**: Multiple modern, ATS-friendly resume templates
- **Customizable Themes**: Color schemes and styling options
- **Responsive Design**: Works perfectly on desktop and mobile devices

### 🔒 Privacy & Security

- **Local Data Storage**: Your data never leaves your device
- **No Sign-up Required**: Start building immediately
- **Secure AI Integration**: Optional AI features with your own API key

### 🚀 Advanced Features

- **Drag & Drop Interface**: Reorder sections effortlessly
- **Rich Text Editor**: WYSIWYG editing with formatting options
- **Export Options**: Download as PDF or export data as JSON
- **Real-time Preview**: See changes instantly as you type

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

1. Clone the repository

```bash
git clone <your-repo-url>
cd resume-builder
```

2. Install dependencies

```bash
npm install
```

3. Set up environment variables (optional - for AI features)

```bash
cp .env.example .env.local
# Add your Gemini API key
```

4. Run the development server

```bash
npm run dev
```

5. Open [http://localhost:3000](http://localhost:3000) in your browser

### Docker Setup

```bash
docker-compose up -d
```

## 🤖 AI Configuration

To enable AI-powered features:

1. Get your Gemini API key from [Google AI Studio](https://makersuite.google.com/app/apikey)
2. Add it to your environment variables or configure it in the app settings
3. Start getting intelligent content suggestions!

## 📝 Usage

1. **Choose a Template**: Select from our modern, professional templates
2. **Fill Your Information**: Add your personal details, experience, and skills
3. **Get AI Suggestions**: Use AI to enhance your content with ATS-friendly keywords
4. **Customize Design**: Adjust colors and styling to match your preference
5. **Export**: Download as PDF or save your data for later editing
